# Proyectos de Desarrollo de Interfaces

Este repositorio contiene los **proyectos realizados en la asignatura Desarrollo de Interfaces** del **Grado de Desarrollo de Aplicaciones Multiplataforma (DAM)**. Aquí encontrarás ejemplos prácticos de diseño y desarrollo de interfaces de usuario, siguiendo buenas prácticas y utilizando distintas tecnologías.

## Contenido

Cada proyecto tiene su propia carpeta con su código fuente, recursos y documentación necesaria. Algunos de los aspectos que se trabajan incluyen:

- Aprendizaje y uso de Angular.
- Integración de API REST.
